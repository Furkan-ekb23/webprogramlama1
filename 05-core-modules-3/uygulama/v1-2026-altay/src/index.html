BÖLÜM 01 // DEĞİŞKENLER, DİZİLER, FONKSİYONLARSEC-01

Görev Brifingi: Kule Nasıl Çalışır?

KULE-JS programı kapsamında, JavaScript’in tek iş parçacıklı yürütme modeli ile tarayıcının sunduğu eşzamansız yetenekler (zamanlayıcılar, ağ istekleri, kullanıcı olayları) karşılaştırılmaktadır. Geliştiriciler için çalışma sırasının öngörülebilirliği hayati önem taşır; sırası yanlış anlaşılan hiçbir asenkron kod, DOĞRULANMIŞ ÇALIŞMA katmanına alınamaz.

JavaScript'in tek iş parçacığı vardır: Call Stack (pist) aynı anda tek fonksiyon çalıştırır. Bekleme gerektiren işler (setTimeout, ağ isteği) tarayıcıya devredilir. Böylece pist boş kalır ve sayfa donmaz.

Kule karakterleri

  • Pist = Call Stack (şu an çalışan iş)
  • Bekleme sahası = Web API (zamanlayıcılar, ağ)
  • Acil iniş = Microtask kuyruğu (Promise)
  • İniş sırası = Task kuyruğu (setTimeout, olaylar)
  • Kule = Event Loop

Kule protokolü (sıra zorunlu)

  1. Ana kod bitene kadar pist boşalmaz.
  2. Pist boşalınca tüm acil işler (microtask) yapılır.
  3. Süresi dolan en erken zamanlayıcı alınır.
  4. Her task'tan sonra tekrar acil işlere bakılır.

9.1 Event loop'un basitleştirilmiş modeli


Gerçek tarayıcı daha karmaşıktır (ekran çizimi gibi adımlar vardır) ama sıralama mantığı budur. Radar simülasyonu da aynı kuralı izler.


// Event Loop'un basitleştirilmiş modeli
function eventLoop(anaKod, microtasks, tasks) {
  anaKod();                            // 1) tüm ana kod
  while (microtasks.length) {          // 2) tüm acil işler
    microtasks.shift()();
  }
  while (tasks.length) {               // 3) bir task...
    tasks.shift()();
    while (microtasks.length) {        // ...sonra yine acil işler
      microtasks.shift()();
    }
  }
}


9.2 async/await ile bekleme


Çıktı sırası 1, 2, 3 olur: await fonksiyonu duraklatır ama pisti tutmaz, ana kod devam eder.


async function yukle() {
  console.log("1: istek gönderildi");
  const yanit = await fetch("/api/ucus");   // pist serbest kalır
  const veri = await yanit.json();           // metni nesneye çevir
  console.log("3: veri geldi", veri.durum);
}

yukle();
console.log("2: ana kod devam ediyor");

9.4 Bilinmesi gereken teknik notlar


  • setTimeout(f, 0) "hemen" demek değildir. Önce mevcut kod ve tüm microtask'lar biter.
  • İç içe zamanlayıcılar belirli bir derinlikten sonra tarayıcı tarafından en az 4 ms'e sabitlenebilir.
  • Arka plandaki sekmelerde tarayıcılar zamanlayıcıları yavaşlatabilir.
  • Sürekli yeni microtask üreten bir kod, task kuyruğunu aç bırakır ve sayfa donar.
  • Pisti uzun süre tutan iş, ekranın yenilenmesini de engeller.
